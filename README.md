# Lunar Mission Navigator

An interactive, frontend-only lunar mission planning concept for NASA Space Apps Challenge 2026. All mission results are labeled simulated. This independent concept is not an official NASA product.

## Run

Requires Node.js 20.9+.

```sh
npm ci
npm run dev
```

Open http://localhost:3000.

```sh
npm test
npm run typecheck
npm run check:contract
npm run build
```

The production build exports a static site to `out/`. Serve that directory with any static host. There is no runtime backend service, authentication, database, or scientific API integration. The `backend/` directory is an offline 40 m validation pipeline; the shipped data under `public/data/` is generated by `scripts/` and read by the browser.

`metadataBase` — the base that turns the Open Graph image path into an absolute URL — is resolved at build time from the first of `NEXT_PUBLIC_SITE_URL`, `VERCEL_PROJECT_PRODUCTION_URL`, `VERCEL_URL`, `URL`, `DEPLOY_PRIME_URL` or `CF_PAGES_URL` that is set, so the usual hosts need no configuration. Set `NEXT_PUBLIC_SITE_URL` when none of them is; with nothing set the share card falls back to `http://localhost:3000`.

## Experience

- Cinematic landing and a textured 3D Moon with orbit, zoom, south-pole focus, selectable markers, and illustrative overlays.
- Shared site, UTC dates, and requirements across Explorer, Site Comparison, Mission Windows, and Mission Brief.
- Deterministic visibility intervals, qualifying-window selection, playback, and an illustrative horizon chart.
- Keyboard controls, onboarding, mobile configuration sheet, reduced motion, and static fallback.
- Print-to-PDF mission brief through the browser print dialog.

## Data model

`lib/science.ts` reads the bundled `public/data/manifest.json`, the per-site hourly JPL Horizons ephemeris, and the 2 m/20 m terrain-skyline profiles. It computes sunlight, Earth visibility, and operating windows in the browser. The terrain is an 80 m LOLA `LDEM_80S_80M` resampling; `docs/DATA.md` documents the sources, formats, and limits. `schema/data-contract.schema.json` is the machine-readable contract for those files; `lib/data-types.ts` is generated from it, and the Python writers validate against it. The `backend/` pipeline independently recomputes the skyline from the 40 m `LDEM_85S_40M` product and compares the two; it is not a runtime dependency.

Lighting, horizon positions, coverage, and elevation grid are estimates, not scientific results. Marker labels are offset for readability. No safety score or NASA-derived forecast is produced.

## Stack

Next.js App Router, React, TypeScript, Tailwind CSS, shadcn-style Radix UI foundations, Motion, Three.js, React Three Fiber, Drei, Recharts, Lucide, Geist, and Space Grotesk.
