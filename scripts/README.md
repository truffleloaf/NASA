# Data generation — the only writer of `public/data/`

Everything under `public/data/` is generated by this directory:

- `terrain.py` — 80 m `LDEM_80S_80M` resampling, terrain binary/header, 2 m/20 m horizon
  profiles, `manifest.json`
- `ephemeris.py` — hourly JPL Horizons Sun/Earth rows and source metadata
- `validate_ephemeris.py` — `validation.json` reference crossings
- `check_data.py` — offline integrity checks

`backend/` is an independent 40 m validation pipeline. It reads these assets for the
cross-product check and **must not write here**. The old `backend/export/data/` and
`backend/pipeline/export_data.py` were removed so there is no second writer.

Regenerate with the commands in `docs/DATA.md` ("Reproduce"), then run:

```sh
npm test
npm run typecheck
npm run build
```

Do not hand-edit a number in `public/data/`: the frontend statically imports
`manifest.json`, `terrain/polar-1024.json` and `validation.json`, and the methods page will
publish whatever is committed. CI runs a read-only cross-product check on changes to
`public/data/`, `backend/`, `scripts/` and `docs/DATA.md`.
